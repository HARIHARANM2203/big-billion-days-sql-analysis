# AI Usage Log

## Project
Big Billion Days SQL Analysis and Dashboard

## Purpose of AI Assistance
AI assistance was used to understand SQL queries, troubleshoot errors, clean spreadsheet data, and prepare documentation for the project.

## Tasks Supported by AI

1. **SQL Query Development**
   - Helped understand and write SQL queries for order analysis.
   - Explained filtering, sorting, aggregation, joins, and grouping.
   - Assisted with checking query outputs.

2. **Data Cleaning**
   - Helped clean customer first and last names using Excel formulas.
   - Assisted with looking up product categories and unit prices.
   - Helped calculate revenue using quantity and unit price.

3. **Data Validation**
   - Helped verify completed order counts and total recorded revenue.
   - Assisted with comparing spreadsheet results against SQL outputs.

4. **Dashboard Preparation**
   - Helped plan PivotTables and charts for regional revenue, sales representative revenue, and monthly completed orders.
   - Assisted with documenting the dashboard design and business recommendations.

## Human Verification
The project owner ran the SQL queries, reviewed spreadsheet formulas, checked outputs, and created the PivotTables and charts. AI-generated suggestions were used as assistance and should be verified against the actual dataset.

## Limitations
AI suggestions may contain errors. Final results and business conclusions must be checked against the source data and query outputs.

## Conclusion
AI assistance supported learning, debugging, data cleaning, validation, and project documentation. The final project should reflect verified results from the actual dataset.
