# Big Billion Days - SQL Analysis

## Project Overview
This project analyzes Big Billion Days sales data using SQL.

## Tools Used
- SQL Compiler: SQLite Online
- SQL Dialect: SQLite

## Project Structure
- sql: SQL schema and query files
- results: Query results in Markdown
- data: CSV exports
- docs: Project documentation
